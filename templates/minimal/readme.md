<h1 align="center">@nessframework/minimal</h1>

<p align="center">Minimal TypeScript starter for Ness.js.</p>

The compact official Ness.js TypeScript starter. It includes one React page, strict TypeScript, one NestJS health controller, SSR, prerendering, and the production server bridge.

```bash
ness new my-app --template minimal
```
