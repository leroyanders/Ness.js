<h1 align="center">@nessframework/dashboard</h1>

<p align="center">Dashboard starter for Ness.js and NestJS.</p>

The official Ness.js dashboard starter. It includes a responsive admin shell, typed KPI and activity data, a NestJS metrics controller, strict TypeScript, SSR, and production configuration.

```bash
ness new admin --template dashboard
```
